# 成片层本地音频与字幕（P6-D）

本文记录 P6-D 的最小合同。音频、字幕和包装属于**成片层**，不是镜头版本的一部分。

## 范围

- 成片画面仍只读取**当前有效镜头视频版本**。
- 背景音频、字幕文本/SRT、音量、是否保留原视频音频，保存在项目级 `assembly_settings`。
- 不接入 TTS、音乐生成、字幕大模型或完整用户上传系统。
- 只允许当前项目资产目录内已登记的本地音频（`.wav` `.mp3` `.m4a` `.aac` `.ogg`）和 SRT。
- 未启用音频和字幕时，合成行为与 P6-C 一致：concat 后 `-an`。
- GET `/assembly` 返回 `source_audio_available`、`source_audio_shot_count`、`source_audio_used`，供前端摘要和刷新恢复。

## 失效与历史

- 上游镜头当前版本变化后，`assembly_stale=1`。
- 成片配置保存且已有成片时，同样 `assembly_stale=1`。
- 重新合成只读取当前有效镜头版本。
- 旧 `final-video` 留在资产历史中，不会被删除覆盖。

## 音频策略

未启用原声、背景音和字幕时，仍走 P6-C 单次 concat + `-an`。

当「保留原视频音频」开启且至少有一个镜头有音轨时，采用两阶段合成，不修改 `shot_versions`：

1. 每个镜头先规范化为 1280×720、24fps、yuv420p。有音轨则转 AAC 44100Hz 立体声并 `apad`/`atrim` 对齐画面；无音轨则只在该片段补静音，便于拼接，不把静音当成“存在原声”。
2. 再拼接规范化片段。若同时启用背景音，原声音量 1.0、背景音按 `audio_volume` `amix`；仅背景音时输出背景音；仅原声时保留拼接后的原声。
3. 背景音短于成片则循环补齐，长于成片则裁剪。最终音轨时长与视频时长一致。
4. 全部镜头都没有音轨时，即使开启保留原声也不会伪造音轨；`source_audio_used=false`。

## 字幕策略

- 可填写纯文本（生成临时 SRT）或选择项目内 SRT。
- 使用 FFmpeg `subtitles` 滤镜烧录到画面，不作为独立字幕流。
- 本机缺少 libass 或可用字体时，配置校验失败并返回中文说明，测试记 `SKIP`，不得伪装通过。

## 安全

- 路径必须是 `/assets/{project_id}/{filename}`，解析后必须落在当前项目目录。
- 拒绝目录穿越、其他项目资产、目录外文件和不存在文件。
- 失败不登记无效 `final-video`，不错误清除 `assembly_stale`。
- 用户可见错误为中文可执行说明，不含 FFmpeg 命令、密钥或本机敏感路径。
- 临时 concat/SRT/packed 文件在成功、失败和异常路径都会清理。

## 明确不做

完整 TTS、配乐生成、复杂字幕时间轴编辑器、通用文件上传、用户系统、部署。
